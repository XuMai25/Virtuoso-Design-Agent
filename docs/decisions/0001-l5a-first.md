# 0001：先做 L5A 受限闭环

- 状态：已采纳
- 日期：2026-07-19

## 决策

以 L5B 单模块设计代理为产品目标，但从 L5A 的反相器纵向切片开始。工具同时支持局部能力和完整闭环，不把所有请求强制转换成“从规格到最终设计”。

## 原因

现有 Bridge 已验证 OA schematic/layout 写入与读回、Spectre、Maestro、`auCdl`、`strmout`、Calibre DRC/LVS。当前主要缺口是稳定任务契约、统一规格与证据语义、参数搜索/失败恢复/预算，以及局部任务接口。反相器足够小，可以先暴露编排问题。

## 结果

- 首版不做 UI、数据库、微服务或内置 LLM。
- 真实 adapter 只承诺反相器能力；其他电路先定义 Gate。
- 默认 plan-only，真实执行需要多重授权。
- demo 结果必须标为软件推断。
- OA 自动 netlisting closure 是反相器后的首要技术债。
